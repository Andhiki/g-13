# Sumber, inspirasi, dan hak pihak ketiga

Lisensi proyek untuk karya asli tidak mengubah hak atas materi pihak ketiga.
Daftar ini mencatat sumber yang diketahui; ini bukan bukti izin redistribusi.

| Materi | Asal dan ketentuan |
| --- | --- |
| Inspirasi peta kurikulum | [course.csui.dev](https://course.csui.dev/). Dikreditkan sebagai inspirasi konsep; kode dan aset visual situs tidak disalin. Atribusi ini tidak menyatakan kerja sama atau pengesahan. |
| Komponen UI dan token AlignUI | Lihat [notice MIT AlignUI](licenses/alignui.txt) serta keputusan penggunaan [AlignUI](docs/adr/0002-alignui-source.md). Pertahankan notice tersebut. |
| Arsip ujian Himakom UGM | Nama mata kuliah dan metadata berkas bersumber dari [arsip Himakom UGM](https://himakom.ugm.ac.id/exam/) beserta folder Drive yang ditautkan. Pengelompokan dinormalisasi menjadi mata kuliah dan tahun. PDF tetap di Drive sumber; hak atas isi berkas tetap milik pemiliknya dan tidak dilisensikan ulang oleh proyek ini. |
| Dokumen UGM dan ekstraksi | Sumber ada di `output/sources/`; page manifests dan audit terstruktur ada di `output/data/`; setiap slice menyimpan sumber dan provenance baris. Tidak ada pemberian lisensi ulang atas isi dokumen UGM. Izin redistribusi PDF, snapshot, dan teks ekstraksi masih perlu dikonfirmasi. |
| Logo HIMAKOM UGM | `apps/web/public/brand/himakom-*.png` dan salinan trailer di `apps/trailer/public/brand/himakom.png`; aset resmi dari [HIMAKOM UGM](https://himakom.ugm.ac.id/), sumber dicatat di [asal aset](apps/web/public/brand/README.md). Berkas tidak dimodifikasi. Hak logo tetap milik pemiliknya dan tidak dilisensikan ulang oleh proyek ini. |
| Logo OmahTI | `apps/web/public/brand/` dan salinan trailer di `apps/trailer/public/brand/omahti.svg`; [asal aset](apps/web/public/brand/README.md). Hak merek dan logo tetap milik pemiliknya. Pemakaian dalam aplikasi bukan izin penggunaan ulang oleh fork. Izin penggunaan/redistribusi perlu dikonfirmasi. |
| GIF Sonic | `apps/web/public/theme/sonic-dancing.gif`; [asal aset](apps/web/public/theme/README.md). Sumber Tenor dan referensi portfolio-magic tidak membuktikan lisensi terbuka. Konfirmasi izin atau ganti dengan aset orisinal/berlisensi jelas sebelum mempromosikan paket aset sebagai bebas digunakan ulang. |
| Dependensi dan font | Lisensi masing-masing paket tetap berlaku; periksa notice di paket yang didistribusikan. `bun.lock` mengunci versi dependensi. |
| Font Geist | [Geist oleh Vercel](https://github.com/vercel/geist-font), didistribusikan melalui `@fontsource-variable/geist` dengan lisensi SIL Open Font License 1.1. Font digunakan tanpa modifikasi; notice tersedia di paket dan salinan untuk trailer di `apps/trailer/public/geist-OFL.txt`. |

Kontributor harus menyertakan URL asal, pemilik, lisensi, serta modifikasi untuk
materi pihak ketiga baru. Atribusi saja tidak menggantikan izin pemakaian.
