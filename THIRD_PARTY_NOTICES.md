# Sumber, inspirasi, dan hak pihak ketiga

Lisensi proyek untuk karya asli tidak mengubah hak atas materi pihak ketiga.
Daftar ini mencatat sumber yang diketahui; ini bukan bukti izin redistribusi.

| Materi | Asal dan ketentuan |
| --- | --- |
| Inspirasi peta kurikulum | [course.csui.dev](https://course.csui.dev/). Dikreditkan sebagai referensi konsep berdasarkan riwayat proyek; tidak menyatakan kerja sama atau pengesahan. Jika kode/asetnya diadaptasi, lisensi upstream harus diverifikasi dan notice dipertahankan. |
| Komponen UI dan token AlignUI | Lihat [notice MIT AlignUI](docs/licenses/alignui.txt) serta [catatan adaptasi](docs/design-system.md). Pertahankan notice tersebut. |
| Dokumen UGM dan ekstraksi | `output/sources/`, `output/data/`, serta data kurikulum/silabus di `src/data/`. Sumber dan batas interpretasi dicatat di [discovery](docs/discovery.md), [ekstraksi 2021](docs/ilkom-2021-extraction.md), dan [ekstraksi 2026](docs/ilkom-2026-extraction.md). Tidak ada pemberian lisensi ulang atas isi dokumen UGM. Izin redistribusi PDF, snapshot, dan teks ekstraksi masih perlu dikonfirmasi. |
| Logo OmahTI | `public/brand/`; [asal aset](public/brand/README.md). Hak merek dan logo tetap milik pemiliknya. Pemakaian dalam aplikasi bukan izin penggunaan ulang oleh fork. Izin penggunaan/redistribusi perlu dikonfirmasi. |
| GIF Sonic | `public/theme/sonic-dancing.gif`; [asal aset](public/theme/README.md). Sumber Tenor dan referensi portfolio-magic tidak membuktikan lisensi terbuka. Konfirmasi izin atau ganti dengan aset orisinal/berlisensi jelas sebelum mempromosikan paket aset sebagai bebas digunakan ulang. |
| Dependensi dan font | Lisensi masing-masing paket tetap berlaku; periksa notice di paket yang didistribusikan. `bun.lock` mengunci versi dependensi. |
| Font Geist | [Geist oleh Vercel](https://github.com/vercel/geist-font), didistribusikan melalui `@fontsource-variable/geist` dengan lisensi SIL Open Font License 1.1. Font digunakan tanpa modifikasi; notice tersedia di paket. |

Kontributor harus menyertakan URL asal, pemilik, lisensi, serta modifikasi untuk
materi pihak ketiga baru. Atribusi saja tidak menggantikan izin pemakaian.
