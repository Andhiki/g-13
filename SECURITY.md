# Melaporkan celah keamanan

Perbaikan keamanan ditujukan untuk versi terbaru di branch `main`.
Versi lama belum memiliki dukungan pemeliharaan terpisah.

Jangan melaporkan celah yang dapat dieksploitasi, token, atau data pribadi melalui
issue atau PR publik. Gunakan **Security → Advisories → Report a vulnerability**
di [repo GitHub](https://github.com/Andhiki/g-13/security/advisories/new)
jika private vulnerability reporting sudah diaktifkan.
Jika tombol tersebut belum tersedia, hubungi [@Andhiki](https://github.com/Andhiki)
melalui kanal privat di profilnya untuk meminta jalur pelaporan; jangan mengirim
detail sensitif sebelum kanalnya dipastikan privat.

Sertakan komponen/commit terdampak, langkah reproduksi minimal, dampak, dan usulan
perbaikan bila ada. Gunakan data contoh. Beri maintainer waktu untuk menyelidiki
dan mengoordinasikan perbaikan sebelum publikasi. Belum ada SLA atau program bounty.

Kesalahan data kurikulum biasa dapat dilaporkan melalui GitHub Issues.
