# Issue tracker

Issues live in `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, numbered from 01 in dependency order. Write one file per ticket.

Each ticket includes what to build, acceptance criteria, Blocked by, and Status. Reference blockers by number and title. Append discussion under a Comments heading.

Specs live in `.scratch/<feature-slug>/spec.md`. To fetch a ticket, read its file. To publish, create its file.
