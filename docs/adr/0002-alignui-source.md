# Use AlignUI component source in the web app

Use MIT-licensed AlignUI component source and design tokens, adapted into `apps/web/src/ui/`, rather than adding a runtime component package. Standard controls keep AlignUI behavior and variants; domain-specific layouts remain in their owning feature. The source is the AlignUI Next.js TypeScript starter at commit `f37bd913a058ceca39d5bfc2369ec420018e5716`; retain its license in `licenses/alignui.txt`.
